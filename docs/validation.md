## 边界与复现

UI 测试与计时分别使用新建的 `TVViewingGuard_GoogleQA` 与 `TVViewingGuard_QA`，没有操作 B3p 或原有共享模拟器。测试结束关闭并删除这两个专属 AVD；保留日志、截图、APK 和可复现测试源码。

Instrumentation 结束会终止目标进程，可使系统暂时把无障碍服务标为 crashed；测试套件之间显式重置专属模拟器的授权状态。不要把测试工具造成的进程终止当作产品的后台持续运行证明。本机 ADB 成功仅证明该测试镜像，不推广至所有 Android9、其他固件或真实视频 App；真实设备仍需逐机确认，完成授权后应关闭 ADB 调试。
