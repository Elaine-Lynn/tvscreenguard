# Security

Do not post parent PINs, ADB keys, device addresses, diagnostics containing personal data, or release signing material in issues or pull requests.

Report vulnerabilities privately through the repository's GitHub private vulnerability reporting feature when available. Please include the affected version, device/Android version and a minimal reproduction without personal data.

Viewing protection depends on accessibility access and the device's background policies. It is not a tamper-proof system parental control. See the README for supported behaviour and limitations.

Release signing keys are kept outside the repository and CI. Production APK certificates must match the public fingerprint recorded in docs/release-1.0.14.md. Public certificate fingerprints and APK checksums are verification data, not private keys.
